# 管理員通知管理

`/管理員`（`/admin`）需在伺服器內執行，並具有「管理伺服器」權限。操作結果只有操作者可見。

支援自動簽到、自動兌換、即時便箋提醒、Auto Mimo、新聞頻道訂閱。只處理本伺服器已啟用的頻道通知；不改動私訊、其他伺服器或已停用的通知。

## 移動

- `/admin move feature:autoDaily channel:#新頻道`：移動本服的自動簽到頻道通知。
- 加上 `source:#舊頻道` 可只處理指定來源。
- `/admin move feature:news channel:#新頻道 source:#舊頻道`：搬移一份新聞訂閱。目標已有訂閱（包括已停用）時略過，雙方設定皆保留。
- `feature:all` 涵蓋五種類型。未指定來源時移動符合條件的個人通知，並回報新聞因缺少來源而略過。

Mimo 按帳號處理。新聞按頻道處理，不依建立訂閱的管理員篩選；保留語言、分類、標記角色與分類起算時間。新聞目標必須符合原新聞功能的頻道及權限限制。搬移以交易完成，來源待送工作會取消，已保存的舊新聞不會重新排送；已送出的 Discord 訊息不搬移。

## 停用

- `/admin remove feature:autoDaily user:@使用者`：停用該使用者在本服的自動簽到通知。也可使用 `userid`。
- `/admin remove feature:autoMimo user:@使用者`：停用該使用者所有符合條件的 Mimo 帳號頻道通知；可加 `source` 限定來源。
- `/admin remove feature:news source:#頻道`：停用該頻道的新聞訂閱，不需要使用者參數。

「刪除」只停用通知目的地；自動簽到、兌換及 Mimo 執行狀態、排程、獎勵與其他設定保留。便箋的各提醒項目也會保留。

## 結果與更新

結果按類型列出成功、略過、衝突及失敗筆數；「沒有符合條件」或「未指定新聞來源」等情況會以一項略過說明。無權限、成員查詢失敗或設定已改變時，不會強制覆寫或停用該筆通知。不同設定逐筆處理，部分失敗不會回滾其他已成功項目，可依結果重試。

無需資料庫遷移。編譯並透過既有部署方式重啟機器人後，啟動流程會重新註冊斜線指令。
