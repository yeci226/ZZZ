# 快速設定與功能提示

執行 `/setup`（繁中 `/快速設定`），或從 `/settings` 首頁進入快速設定。面板只有本人看得到與操作。四項功能各自開關，點擊立即生效；開啟後可進入詳細設定。完成只關閉面板，不會撤回已儲存的變更。

舊使用者保留原本的時間、通知、獎勵與提醒條件；停用後重新啟用不會重設。新功能預設私訊通知，自動兌換與 Mimo 預設不提及使用者。

| 功能 | 首次啟用的設定 |
|---|---|
| 自動簽到 | 從台灣 UTC+8 的 24 個整點，選目前已啟用使用者人數最少的時段；並列時隨機選擇，之後固定使用，可自行修改 |
| 自動兌換 | 自動處理公開兌換碼，私訊結果，不提及 |
| Auto Mimo | 所有可用 HoYoLAB 帳號，只兌換菲林，私訊結果，不提及 |
| 遊戲提醒 | 電量回滿前 60 分鐘、每日截止前 3 小時、每週／活動截止前 24 小時，其餘沿用既有條件 |

## 多帳號

Mimo 每個 HoYoLAB 帳號使用一個領獎 UID。有既有有效 UID 就保留，只有一個可用 UID 時自動帶入，多個候選時再選擇。Mimo 會取得活動積分並依設定消耗積分兌換獎勵。

可用帳號先啟用；待選 UID、登入失效或由其他使用者管理的帳號各自顯示原因。詳細設定可逐帳號調整，再按「開啟其餘帳號」重試。總開關可停用全部已綁定、由本人管理的 Mimo 帳號。之後新增的帳號需再次設定。

登入失效時可重新綁定後按「重新檢查」。停用不需要有效登入。通知傳送永久失敗只停用通知，不會因此重複執行兌換或切換至其他通知位置。

## 隨機功能提示

`/daily`、`/codes`、`/note check`、`/banner`、`/profile` 與 `/team` 的適用結果，會在文字區顯示一行隨機小字提示。每個指令從三則相關提示中等機率選擇，涵蓋七種語言。

同一則訊息切換角色、更新狀態或背景同步時保留同一句；新的指令結果重新抽選。提示不加入 Components V2、載入中、登入或權限錯誤；超過文字限制時省略提示，保留原內容。沒有每位使用者的提示歷史紀錄。

## 驗證與發布

相關測試使用模擬 Discord／官方 API 與記憶體 SQLite，不會傳送真實通知或消耗 Mimo 積分。發布時依現有流程編譯與重新啟動，指令載入器會註冊 `/setup`；既有使用者不需要資料遷移。
