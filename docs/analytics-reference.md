# ZZZ Analytics 參考資料

`/profile` 主頁新增「依持有角色找隊伍」，單人及多人角色卡新增「參考隊伍／參考配裝」。原 `/team` 保留；新功能不需要註冊新指令。

參考視窗僅對發起 `/profile` 的使用者顯示，可切換隊伍、配裝及招式傷害彙總，逐筆翻頁、篩選整隊角色是否持有，並開啟來源影片或戰鬥日誌。角色名稱優先使用帳號已取得的本地化名稱，裝備名稱沿用來源英文；介面提供中文及英文回退。入口 30 分鐘後失效，重啟也會清除。

資料來自 `https://zzz.analytics.moe/api/runs`。只讀取公開快照，不向外站傳送 UID、Cookie、Discord ID 或角色清單。每個機器人程序共用一小時記憶體快取；刷新失敗可使用未滿 24 小時的快取並標示，失敗後至少一分鐘再嘗試。工作階段固定使用首次成功載入的快照，避免翻頁時結果移動。

排除來源標記 Beta、Beta 歸檔、待改善及格式不合法的紀錄；未標記的資料不能據此認定為正式服實測。公開快照中的 `status` 有 `pending` 或缺值，不能當成審核通過標記。來源文件說明使用中性訓練測試環境，因此介面不宣稱正式服排行、帳號預測 DPS 或最佳配隊。持有篩選只比對角色 ID；影畫對照另外顯示，不檢查玩家是否具有相同音擎及驅動盤。

「匯出參考紀錄」只匯出正規化的來源紀錄及擷取時間，明確設 `verified: false`、`calibrationReady: false`，不含帳號資料。招式資料是來源彙總，不是逐擊時間軸；原始日誌以來源連結提供。沒有接入本地模擬校準器，也不改變戰鬥模擬發布條件。

驗證：`npx jest --runInBand tests/analyticsReference.test.ts tests/profileCharacterSelect.test.ts`、`npx tsc --noEmit`。公開端點不是已確認的穩定第三方 API；格式或服務故障時顯示暫時不可用，不阻擋角色卡本身。
